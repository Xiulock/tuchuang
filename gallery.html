A LITTLE SPACE FOR BEAUTIFUL THINGS

01 / 访问设置

Token 只保存在当前浏览器，不会上传到图床仓库。建议使用仅允许 tuchuang 仓库 Contents 读写的 Fine-grained Token；不要将此管理页面连同 Token 分享给别人。

02 / 上传素材

点击选择文件，或拖拽到这里支持 JPG、PNG、GIF、WEBP、SVG、BMP、ICO、MP3、WAV、M4A、OGG、FLAC、AAC · 可多选

03 / 我的图库

分类保存在 GitHub 仓库中，换设备也能同步。移动图片后旧链接会失效；原有未分类图片的链接保持不变。

♡ 表情包批量管理

可切换任意分类挑选图片，勾选会保留；选择「全部」可查看跨分类素材。音频不会参与表情包导出。

可在任意分类的图片旁填写描述（如“哭哭”），点击「保存名称」。勾选图片后可批量复制链接，或导出小手机格式：哭哭：https://...。未命名的图片会跳过。

让我帮忙命名时，先复制 URL 发给我；我返回「描述：URL」后，粘贴到下面批量回填。也可以粘贴「URL：描述」。

点击“刷新图库”查看文件。
