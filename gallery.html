♡ 表情包批量管理

可切换任意分类挑选图片，勾选会保留；选择「全部」可查看跨分类素材。音频不会参与表情包导出。

可在任意分类的图片旁填写描述（如“哭哭”），点击「保存名称」。勾选图片后可批量复制链接，或导出小手机格式：哭哭：https://...。未命名的图片会跳过。

TXT 默认按「描述：链接」输出；未命名的图片也会导出链接，不会丢失。JSON 可保存选中图片的管理信息。

让我帮忙命名时，先复制 URL 发给我；我返回「描述：URL」后，粘贴到下面批量回填。也可以粘贴「URL：描述」。

全站备份与恢复

备份所有分类、图片索引、描述、收藏、标签、显示名称和筛选偏好；不包含图片原文件或 GitHub Token。全站备份不会删除仓库图片。

导入可选择合并或覆盖管理数据。恢复至 GitHub 需要当前 Token 有写入权限。
